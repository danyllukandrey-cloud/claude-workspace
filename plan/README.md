# ПЛАН — сервіс для ведення плану життя

Проєкт особистого помічника для опису, планування й відстеження прогресу в різних аспектах життя.

## 📊 Про проєкт

**Мета:** створити простий й доступний сервіс, де можна:
- Описати кожен аспект життя (здоров'я, кар'єра, стосунки, навчання і т.д.)
- Встановити цілі й пріоритети
- Відстежувати прогрес
- Спостерігати за розвитком кожної ділянки в час

**Хто це для:** люди, які хочуть мати прозоре й керовне життя.
