# ISSUES — реєстр виявлених нестиковок проєкту «ПЛАН»

Одне місце, куди записуємо кожну знайдену **нестиковку логіки** — розбіжність між тим, що зроблено, що записано в документах, і що заплановано. Мета — не загубити знахідку, щоб пізніше свідомо пошукати рішення, а не натикатись на ту саму проблему повторно як на нову.

## Як цим користуватись

**Це журнал знахідок, а не журнал рішень.** Знайшов нестиковку → допиши рядок сюди одразу, навіть якщо рішення ще нема. Знайшов рішення → онови статус тут, а саме рішення (якщо воно рівня D-NN за критерієм із CLAUDE.md) запиши в `docs/DECISIONS.md` і зв'яжи посиланням. Не видаляй закриті рядки — вони показують, що вже траплялось і як вирішилось.

**Що вважається нестиковкою (пишемо сюди):**
- Документ каже одне, а реальний стан файлів/коду — інше.
- Два документи описують той самий факт по-різному.
- Показник (%, статус фази) не відповідає тому, що видно по чек-листах чи Git-історії.
- Логічна помилка чи прогалина, яку хтось (людина, `pm`, будь-який агент) помітив під час перевірки, але вона не виправляється негайно тут і зараз.

**Що НЕ пишемо сюди:** дрібне форматування, одруківки — їх просто виправляють на місці без запису.

**Формат рядка:** одна нестиковка — один рядок реєстру. Номер `ISS-NN`, наступний вільний — рахувати максимум:

```powershell
Select-String docs\ISSUES.md -Pattern '^\| ISS-(\d+) \|' | ForEach-Object { [int]$_.Matches.Groups[1].Value } | Sort-Object | Select-Object -Last 1
```

## Статуси

| Статус | Значення |
|---|---|
| **відкрито** | знайдено, рішення ще не шукали |
| **у роботі** | рішення обговорюється чи перевіряється |
| **закрито** | вирішено — див. колонку «Рішення / посилання» |
