# T10 — PlanItemEditor.tsx

## Why

[AC-01/AC-02/AC-04](../spec.md) — повноекранний редактор одного пункту: новий (через «+») чи наявний (клік на пункт).

## What

Текстове поле + «Зберегти». Для нового пункту — порожній текст блокує збереження з поясненням (без запиту на сервер). Для наявного пункту — збереження з порожнім текстом викликає `DELETE` (не `PATCH`, за контрактом), непорожній текст — `PATCH`.

## Definition of Done

- [ ] Компонентний тест: створення з текстом викликає create-запит
- [ ] Компонентний тест: створення з порожнім текстом показує повідомлення, запиту немає
- [ ] Компонентний тест: очищення тексту наявного пункту й збереження викликає delete-запит, не update
- [ ] Компонентний тест: зміна тексту наявного пункту на інший непорожній викликає update-запит
- [ ] lint + vet чисто
