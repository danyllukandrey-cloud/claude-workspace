# T12 — Підключити допомогу агента в чаті

## Why

[AC-06/AC-09](../spec.md), [sad.md §6 flow 4](../sad.md) — агент опційно формулює текст, пропозиція лишається лише в чаті, підтвердження створює пункт тим самим ендпоінтом, що пряме введення.

## What

Розширити розпізнавання наміру агента (`ask-agent.ts`) на «додати пункт плану», підключити підтверджену пропозицію до `POST /api/v1/plan-items` (T4/T8) через наявний `sendChatMessage`-канал — без нового `pending`-стану на сервері (sad.md §4 п.3).

## Definition of Done

- [ ] Інтеграційний тест: підтвердження пропозиції в чаті створює пункт з підтвердженим текстом
- [ ] Інтеграційний тест: непідтверджена пропозиція не з'являється на сторінці ПЛАН
- [ ] lint + vet чисто

## Notes

Торкається чужого модуля (`agent/`) — за правилом композиції ([architecture-map.md](../../../architecture-map.md) §Конвенції) підключення йде через композиційний корінь, не прямий імпорт з `plan-horizons` в `agent` чи навпаки.
