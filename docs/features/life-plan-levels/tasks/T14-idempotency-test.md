# T14 — Тест: ідемпотентність подвійного збереження

## Why

[spec.md §6 NFR](../spec.md) — два натискання «Зберегти» в межах 1 секунди не створюють дублю. Не прив'язано до конкретного AC (вимога нефункціональна), але явно узгоджена вимога.

## What

Тест: два `POST /api/v1/plan-items` з однаковим `Idempotency-Key` протягом 1 секунди повертають той самий `plan_item.id`, у базі лишається один рядок.

## Definition of Done

- [ ] Тест підтверджує єдиний рядок у `plan_item` після двох запитів з тим самим ключем
- [ ] Тест підтверджує, що різні ключі створюють різні рядки (немає хибного дедуплікування)
- [ ] lint + vet чисто
