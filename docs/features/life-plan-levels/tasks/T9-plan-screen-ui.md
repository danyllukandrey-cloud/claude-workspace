# T9 — PlanScreen.tsx

## Why

[AC-01/AC-08/AC-11](../spec.md) — головний екран ПЛАН, три горизонти одночасно, з пунктами і без.

## What

- [ ] Компонентний тест: порожній горизонт показує кнопку «+», не порожнє повідомлення
