# Changelog — life-plan-levels

## life-plan-levels — сторінка "ПЛАН": три часові горизонти намірів

**What:** нова сторінка ПЛАН — три фіксовані горизонти (тактичний / оперативний / стратегічний), кожен зі своїм списком пунктів-намірів. Пункт додається напряму або через підтвердження в чаті з агентом; чекбокс "виконано" — реверсивний тумблер; "видалення" — це очищення тексту в редакторі (м'яке, ніколи фізичне).

**Why:** [spec.md](../spec.md) §1/§2 — користувачу бракувало місця формалізувати наміри окремо від Структури й Карток, на трьох горизонтах планування замість одного плаского списку. Архітектурних рішень (ADR) для цієї фічі не знадобилось — [sad.md](../sad.md) §9 пояснює чому: усе успадковує вже прийняті рішення `structure` (власний модуль верхнього рівня) і D-114 (лише онлайн-режим).

**How to use:** `GET/POST/PATCH/DELETE /api/v1/plan-items`, повний контракт — [openapi.yaml](../contracts/openapi.yaml). Приклад: `POST /api/v1/plan-items {"horizon": "tactical", "planText": "Пробігти 5 км"}` створює пункт; `PATCH /api/v1/plan-items/{id} {"done": true}` позначає виконаним; `DELETE /api/v1/plan-items/{id}` м'яко прибирає пункт зі списку.

**Operational notes:**
- Migration: `1789912813806_create-plan-item.sql` — одна таблиця `plan_item`, застосовується при деплої, відкатується чисто (`down` промотовано разом).
- Feature flag / config: <!-- none -->
- Rollback: `migrate down` цієї міграції + відкат деплою; фронтенд-модуль (`src/plan-horizons/`) і його підключення в навігації (`App.tsx`) можна відкотити тим самим ревертом коміту.

**Acceptance criteria delivered:** AC-01 (пряме додавання пункту), AC-02 (порожній/пробільний текст відхиляється), AC-03/AC-03b (реверсивний чекбокс "виконано"), AC-04 (очищення тексту = м'яке видалення, whitespace-only не є "порожнім"), AC-05 (ідемпотентність збереження, 1с вікно), AC-06 (кожен горизонт має власну кнопку "+"), AC-07 (авторизація — 404 для чужого/неіснуючого пункту, не підтверджуємо й не спростовуємо), AC-08 (усі три горизонти видно одночасно, з датою додавання), AC-09 (підтверджений у чаті пункт з'являється на сторінці ПЛАН одразу, без ручного перезаходу), AC-11 (порожній горизонт має робочу кнопку "+", не порожній екран-заглушку).
