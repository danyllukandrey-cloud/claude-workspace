# 0003 — Give Structure its own top-level module, not shared/priority

- **Status:** Accepted
- **Date:** 2026-08-24
- **Deciders:** Андрій Данилюк (з Клодом під час Socratic-проходу `design`)

## Context

`architecture-map.md` уже має заготовку `shared/priority/` («спільна модель пріоритету/навантаження — тепер частково покрита рівнем Структури (D-29), деталі UI ще не спроєктовані»). Структура тепер набагато ширша за групування: декларація «картина світу», окремий екран схеми, екран зведеної аналітики (AC-01…AC-13), літопис змін (AC-15). Треба вирішити, де саме в дереві коду це живе, перш ніж писати `tasks`/`implement`.

## Decision drivers

- Структура — не інстанс generic-картки і не розмножується (D-29, `docs/CONTEXT.md`) — концептуально інша сутність, ніж будь-що в `cards/`.
- `shared/priority/` заплановано вузько (лише пріоритет/навантаження), а не як дім для декларації, трьох навігаційних екранів і домену агрегату.
- Конвенція продукту: кожна логічно окрема сутність — власна папка з `domain/` + `ui/` (D-17, ADR-0004 продуктовий), як `cards/life-area-card/`.

## Considered options

1. **Новий топ-рівень модуль `plan/app/src/structure/`** — окрема папка з власними `domain/` + `ui/` + `index.ts`, зареєстрована в app-shell окремо від `cards/`.
2. **Розширити `shared/priority/`** — увесь код Структури (декларація, три екрани, агрегат, літопис) заводиться всередині вже наявної заготовки.

## Decision outcome

**Chosen:** Option 1. `shared/priority/` — назва й задум під вузьку задачу (пріоритет/навантаження), а Структура носить куди ширший набір відповідальностей (декларація, три навігаційні екрани, агрегат, літопис). Розтягувати вузько названу заготовку під усе це заплутає навігацію в коді — назва папки перестане відповідати вмісту.

## Consequences

**Positive**
- Чітка межа в коді: `cards/` — генерик-картки, `structure/` — єдиний на користувача об'єкт, `shared/` — те, що дійсно спільне для обох. Знаходити код за призначенням легко.
- Симетрія з уже усталеним патерном `cards/life-area-card/domain+ui`.

**Negative**
- `architecture-map.md` §Інвентар модулів потребує правки — рядок про `shared/priority/` як «майбутній дім Структури» більше не чинний, замінюється новим модулем.

**Neutral**
- `shared/priority/` заготовка лишається порожньою й, імовірно, видаляється при `implement` — якщо жодна інша фіча не претендує на спільну модель пріоритету поза Структурою.
