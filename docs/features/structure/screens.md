## New components

| Component | Why no existing primitive fits | Registered in design-system |
|---|---|---|
| `TextArea` | Багаторядкове поле вводу — `TextField`/`NumberField` в інвентарі однорядкові | pending |
| `LayoutModePicker` | Вибір одного з 3 фіксованих варіантів (сегментований перемикач) — жодного picker-примітиву нема | pending |
| `CardPicker` | Вибір цільової картки з динамічного списку активних карток — інша природа даних, ніж `LayoutModePicker` | pending |
| `Spinner` | Індикатор завантаження — `design-system.md` фіксує спінер (не skeleton) як конвенцію, компонента ще не існує | pending |
| `Banner` | Інлайн-повідомлення (успіх/помилка/офлайн) — `design-system.md`: «помилки інлайн, ніколи `alert`/`confirm`», потрібен носій для цього правила | pending |
| `ConfirmDialog` | Підтвердження дії з наслідками, що не скасовуються одним кліком (AC-11b) | pending |
| `LayoutGrid` | Сітка клітинок розкладки з drag-and-drop — специфічно для Структури | pending |
| `ProgressBar` | Візуалізація відсотка прогресу картки | pending |
| `GapList` | Список розриву з двома режимами показу (ранг / прапорець) залежно від типу розкладки | pending |
| `Toggle` | Перемикач «перенести/не переносити» на метрику | pending |
| `EmptyState` | Стандартний порожній стан (текст + наступна дія) — `design-system.md` конвенція, компонента ще нема | pending |

Усі — `pending`: жоден код компонента ще не написаний ([`design-system.md`](../../design-system.md) — інвентар лише запланований). `implement` реєструє кожен назад в інвентар, коли пише реальний код.
