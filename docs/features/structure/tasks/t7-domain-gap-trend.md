# T7 — Domain: gap + trend calculation

## Why

[D-61](../../../DECISIONS.md#d-61) (розрив залежить від типу розкладки), [sad.md Потік 9](../sad.md#6-runtime-view).

## What

Чиста функція: дано тип розкладки + поточні позиції + прогреси → якщо «за логікою» — розрив рангу проти прогресу (AC-06); якщо без схеми — прапорець «заявлено важливим, не підтримується» (AC-06b). Друга чиста функція: дано розрив «зараз» і розрив «раніше» (обидва входи — готові числа, звідки вони взялись — задача T14/T10) → напрямок тренду (AC-07).

## Definition of Done

- [ ] Unit test: розрахунок рангового розриву для розкладки «за логікою»
- [ ] Unit test: прапорець для розкладки без схеми, коректно ігнорує ранг
- [ ] Unit test: тренд «росте»/«меншає»/«без змін» для трьох пар входів
- [ ] lint + vet clean

## Notes

Ніколи без вердикту «добре/погано» ([D-60](../../../DECISIONS.md#d-60)) — функція повертає лише числа/напрямок, без оцінки.
