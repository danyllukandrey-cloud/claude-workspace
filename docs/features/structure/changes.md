## Пов'язане

- Скоординована зміна з [`life-area-card` CH-01](../life-area-card/changes.md) — та сама гілка, дубль кнопки «Архів карток» на сторінці Картки.
- CH-02 скоординована з [`life-area-card` CH-02](../life-area-card/changes.md) — джерело поля стану картки.
- Показники для карток без жодного метрик-блоку (напр. Побут/Філософія) — досліджувалось окремо, тепер закривається CH-07.
- CH-03 (частина 2, Архів карток) скоординована з [`life-area-card`](../life-area-card/changes.md) — той самий спільний `ArchiveScreen.tsx`, що живе у фічі `life-area-card`, тут не редагувався (D-134).
- CH-03…CH-10 — знахідки живого тестування 2026-09-21, виконані на гілці `structure-live-fixes` (3 паралельні агенти, кожен в ізольованій worktree: Схема, Аналітика, Декларація) після мерджу `life-area-card-live-fixes` (PR #14) у `main`.
