## Пов'язане

- Скоординована зміна з [`life-area-card` CH-01](../life-area-card/changes.md) — та сама гілка, дубль кнопки «Архів карток» на сторінці Картки.
- CH-02 скоординована з [`life-area-card` CH-02](../life-area-card/changes.md) — джерело поля стану картки.
- Показники для карток без жодного метрик-блоку (напр. Побут/Філософія) — досліджувалось окремо, тепер закривається CH-07.
- CH-03…CH-08 — знахідки живого тестування 2026-09-21 (гілка `life-plan-levels`), виконання відкладено до окремої гілки цієї фічі, за [D-134](../../DECISIONS.md#d-134): наступну незалежну гілку не відкриваємо, поки `life-plan-levels` не змержена в `main`.
