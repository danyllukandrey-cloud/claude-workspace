# ПЛАН

## Що це

Сервіс "ПЛАН" — сервіс, за допомогою якого користувач описує та веде свій план життя.
Складається з Додатку та сайту.

## Для кого

Сервіс призначений для всіх, хто хоче спланувати життя, зрозуміти та дослідити кожен з
його аспектів, відслідковувати прогрес на кожній ділянці, змінювати ієрархію та
пріоритетність. Це сервіс для тих, хто хоче, щоб його життя було для нього ж прозорим та
керованим.

## Яку проблему вирішує

Сервіс вирішує проблему дослідження, планування, спостереження за прогресом та, в
результаті, загальної прозорості життя в цілому. Ті самі проблеми сервіс вирішує і за
умови ведення плану частково — в одному чи кількох аспектах життя (наприклад, "здоров'я"
та "кар'єра").

## Поточний статус

Станом на 2026-07-05 проєкт знаходиться в стадії опису ідеї та розробки документації.

Автор наразі вчиться і досліджує, як правильно розпочати проєкт. Послідовність етапів:

1. Створення картки та її наповнення у тестовому режимі.
2. Архітектура та опис.
3. Перший максимально простий варіант карток з ручним введенням метрик і
   відслідковуванням прогресу + опис стартапу.

> Примітка: поточна розробка (стартова/тестова/навчальна частина) ведеться окремо від
> довгострокового бачення нижче — одне не заважає іншому.
