# .claude/skills — паспорт скілів проєкту

Скіл — набір інструкцій, який Клод підвантажує на вимогу (`/назва-скіла`). У цій папці
лежать скіли двох різних походжень, і плутати їх не можна.

## Наші власні

| Скіл | Що робить |
|---|---|
| `session-brief` | короткий статус проєкту на старті сесії |
| `pm-start` / `pm-end` | план на день і звірка зробленого (див. [`docs/PM-WORKFLOW.md`](../../docs/PM-WORKFLOW.md)) |

Ці ми пишемо й змінюємо самі. Питань немає.

## Скопійовані з курсу (вендоровані)

**Вендорити** — покласти чужий код до себе в репозиторій і далі відповідати за нього
самому, замість підключати зовнішнє джерело.

| Скіл | Оригінал |
|---|---|
| `sdlc-interview` | плагін `sdlc` v3.3.1, скіл `interview` |
| `sdlc-fix-term` | плагін `sdlc` v3.3.1, скіл `fix-term` |

**Джерело:** `github.com/genkovich/agentic-engineering-course-public`,
шлях усередині репозиторію — `modules/6-sdlc/sdlc/plugin/skills/`.
**Автор:** Kyrylo Genkov. **Ліцензія:** MIT — копіювати й змінювати дозволено.

Чому копією, а не прапорцем `--plugin-dir`, як радить урок: [D-36](../../docs/DECISIONS.md).
Коротко — копія їде через Git і працює на обох комп'ютерах, прапорець треба вказувати
щоразу, і шлях на кожній машині свій.

## ⚠️ Три відхилення від оригіналу — читати перед виконанням протоколу

Тексти самих `SKILL.md` ми **не переписували**, щоб їх легко було оновити з курсу.
Тому файл місцями каже одне, а в нас діє інше. Ось повний перелік розбіжностей.

| # | У файлі `SKILL.md` написано | У нас насправді | Чому |
|---|---|---|---|
| 1 | скіл зветься `interview` | папка й команда — `sdlc-interview` | у Claude Code уже є вбудований скіл `interview` (про інше: стрес-тест ідей). Два однакових імені зіштовхнулись би |
| 2 | виклик `sdlc:fix-term` | `sdlc-fix-term` | `плагін:скіл` — синтаксис плагінів; плагіна ми не ставили, скіли лежать просто в папці |

**Відхилення №3 (шлях артефактів) закрито 2026-08-19 ([D-47](../../docs/DECISIONS.md))** —
артефакти фіч перенесені в `docs/features/<slug>/`, як і пише `SKILL.md`. Розведення двох
папок (`Q-4`) більше не діє.

## Як оновити скіл із курсу

1. `git pull` у клоні `agentic-engineering-course-public`.
2. Скопіювати теку скіла заново поверх нашої.
3. **Повернути шапку-вказівник** на початок `SKILL.md` (одразу після блоку `---`) —
   при копіюванні вона затреться:

   ```markdown
   <!-- ЛОКАЛЬНА КОПІЯ. Оригінал: agentic-engineering-course-public, плагін sdlc v3.3.1.
        Відхилення від оригіналу (шлях запису артефактів, назви скілів) описані
        в .claude/skills/README.md. Прочитати README ПЕРЕД виконанням протоколу. -->
   ```

4. Перечитати таблицю відхилень вище — чи всі три ще актуальні для нової версії.
5. Оновити номер версії в цьому файлі.
