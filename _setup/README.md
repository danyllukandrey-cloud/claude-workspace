# _setup — шаблони конфігурації

Тут лежать файли-шаблони, потрібні на кожній машині, але **не потрапляють у git** самі
по собі (бо особисті або глобальні).

> **Інструкція з розгортання — не тут.** Повний покроковий гайд:
> [`docs/SETUP-NEW-MACHINE.md`](../docs/SETUP-NEW-MACHINE.md).
> Цей файл лише описує, що є в папці.

## Вміст

| Файл | Куди копіювати | Чому не в git |
|---|---|---|
| `settings.json` | `.claude/settings.json` | **насправді В git.** Копія на випадок відкату |
| `settings.local.json.example` | `.claude/settings.local.json` | особисті overrides, у `.gitignore` |
| `user-settings.json` | `~/.claude/settings.json` | глобальний рівень, лежить поза репозиторієм |
| `devcontainer/` | `.devcontainer/` | **насправді В git.** Копія на випадок відкату |

## Чому папка взагалі існує

Claude Code захищає `.claude/` і `.devcontainer/` від запису агентом — це навмисно,
щоб агент не міг сам собі переписати дозволи. Тому файли спершу створюються тут,
а користувач переносить їх командою `Copy-Item` вручну.
